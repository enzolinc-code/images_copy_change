# 任务：手机壳图案的「受控变异」

你拿到**一张母款图案**（手机壳整幅画布，1252×2232）。你的工作不是重新画一张图，
而是**在保住爆款基因的前提下，改动指定的那几个变量**。

## 全局铁律（每张都必须遵守）

1. **画布**：输出依然是竖版整幅图案，画幅 9:16，**不要**出现手机壳、壳体边缘、摄像头模组、
   镜头、闪光灯、金属圈、玻璃或反光，**不要**出现绿色底稿色块。
2. **保留 = 原样保留**：下面「必须保留」里列到的部分，形状、位置、大小、笔触、密度
   都要和母款一致，**不要重画、不要"改进"、不要换风格**。
3. **只改指定的变量**：除了「本次要改」那一条以外，其他任何地方都不许动。
   改多了这张图就没有测试价值了。
4. **不要加母款里没有的东西**：不要加水印、签名、边框、logo，不要添加母款里没有的图案元素
   （「本次要改」明确要求加道具时除外）。
   **但母款里已经有的文字必须保留**——位置、大小、颜色、字体感觉都照原样，
   除非「本次要改」那一条明确点名要动它。不要因为"不要加文字"就把它删掉或改成别的字。
5. **不要变脏**：不要出现糊块、接缝、色带、噪点、重复纹理堆叠。
6. 画面情绪基调**保持不变**——这是母款的价值所在。
